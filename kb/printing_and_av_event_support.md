# Printing and AV Event Support

## Printer offline

Confirm scope, device name, power/network status, paper and error indicators. Check the user's selected printer and queue, pause state, and a test page. Avoid clearing another user's jobs without authorization. Record the printer asset tag and any recurring error code.

## Projector or microphone issue

Arrive early for planned events. Confirm room, start time, source device, cable/adapter, input selection, display mode, resolution, microphone channel, battery, receiver, and a known-good spare. Perform an end-to-end test with the event contact and record the final configuration for repeat use.

## Closeout

Confirm the user or event lead is satisfied, return loaned equipment, note damaged or missing accessories, update the asset record, and add a knowledge-base note for repeat failures.
