# Security Incident First Response

## Suspected phishing or malware

1. Keep the user calm and collect the time, device, message source, attachment/link, observed behaviour, and actions already taken.
2. Ask the user to stop interacting with the message or device. Follow the organization's approved isolation procedure; do not improvise destructive cleanup.
3. Escalate immediately to the security or senior IT contact and mark the ticket with the required priority and confidentiality.
4. Preserve relevant details without forwarding a malicious attachment or copying sensitive content into an inappropriate channel.
5. Follow approved guidance for scanning, credential reset, recovery, user communication, and post-incident documentation.

Tier 1 staff should not promise that a device or account is safe before the designated responder has completed verification.
